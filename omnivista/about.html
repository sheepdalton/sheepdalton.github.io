OmniVista

Written by Dr. Sheep "Nick" Dalton and Prof. Ruth Dalton.

Overview

OmniVista is a cutting-edge isovist-generation application, designed to deliver ultra-fast performance and modernized usability. The platform leverages parallel processing, a browser-based interface, and robust privacy features to provide advanced functionality and scalability.

Key Features

OmniVista takes full advantage of parallel processing, unlike traditional single-threaded applications. By utilizing all available CPU cores, users can achieve an 8-10x speed improvement—scaling up to a 32-core desktop—enabling the analysis of higher-density grids and larger spatial areas.

This version of OmniVista runs entirely within a standard web browser. There’s no need for downloads, installations, or licensing. It’s ideal for architects integrating space syntax into their daily workflows, researchers conducting academic studies, and educators teaching in traditional classroom environments. With a simple browser and a modern computer, anyone can access the latest version, complete with recent bug fixes and improvements.

All data remains on the user’s computer. Models and inputs are never shared externally. Users can input data via SVG and generate outputs as SVG color vector files and tables suitable for Excel or statistical analysis.

Incorporating Advanced Technology

  • Traditional isovist metrics (such as area and perimeter).
  • Global structure measures like integration.
  • Aleatory (random) isovists for processing larger areas and narrow passages.
  • Area of overlap isovists that enhance correlation with observed movement.

Future-Proofed Development

OmniVista is continuously updated with new features and algorithms, ensuring that it remains at the forefront of isovist analysis technology.
